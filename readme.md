 # Sajin Komamura — MUGEN Character

## English

This is a personal pet project created to study MUGEN character development while practicing Git and version control.

The character is **Sajin Komamura**, one of my favorite characters from the anime *Bleach*. This is a pilot project for MUGEN, featuring simple code and sprites as a foundation for learning and experimentation.

**MUGEN creator:** Atarax
